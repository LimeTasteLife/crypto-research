# dYdX Chain Client for JavaScript

## TL;DR
The v4-Client TypeScript client is for placing transactions and querying dYdX Chain. Repository: v4-client-js. Uses Node 18 (.nvmrc). Mobile bundling via webpack to native/ios/v4-native-client.js. Releases via `npm version` and a GitHub Action. Pure tooling/dev-setup page.
