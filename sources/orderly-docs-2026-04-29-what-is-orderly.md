# What is Orderly?

## TL;DR
Orderly is a headless omnichain trading infrastructure for perpetual futures. Builders (DEX frontends, wallets, trading teams) integrate via APIs/SDKs to launch branded trading experiences on top of shared liquidity and a common orderbook. Orderly provides the matching engine, settlement rails, and account infrastructure while builders own the frontend and user relationship. The model is analogous to a white-label exchange backend with on-chain settlement.
