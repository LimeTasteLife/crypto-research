# Smart Contract Addresses

## TL;DR
Orderly uses a unified Vault address (0x816f722424B49Cf1275cc86DA9840Fbd5a6167e9) across most chains. Settlement chain is Orderly L2 (chainID: 291, explorer: explorer.orderly.network). Core L2 contracts: Ledger, OperatorManager, VaultManager. Supported mainnet chains include 17 EVM chains plus Solana. Multi-collateral support on Ethereum mainnet: USDC, USDT, YUSD, WBTC, USD1.
