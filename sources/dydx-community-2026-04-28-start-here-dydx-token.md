# DYDX Token

## TL;DR
The DYDX token is dYdX Chain's L1 token serving three purposes: Governance (proposing/voting on proposals), Security (staking weight increases attack cost), Staking (delegators can run validators or delegate to existing validators). Adopted by the dYdX community via Snapshot and on-chain governance.
