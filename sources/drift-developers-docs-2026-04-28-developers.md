# Drift for Developers

## TL;DR
Developer-portal landing page. Drift exposes three first-party SDKs: TypeScript (`@drift-labs/sdk`), Python (`driftpy`), and Rust (`drift-rs`). It also publishes a Data API for read-heavy workloads (analytics, dashboards, historical queries, off-chain data access without running an indexer). Developer guides are organized into four workflows: Market Makers (liquidity provision strategies, JIT, production patterns), Vault Managers, Trading Automation (keeper bots, ops), and Ecosystem Builders (orderbook integration, sending protocol actions).
