# Introduction

## TL;DR
Lighter positions itself as a decentralized trading platform optimized for security, scale, and performance, claiming to be the first exchange to offer verifiable order matching and verifiable liquidations while delivering performance comparable to traditional exchanges. The page is the canonical entry point of the docs and lists two end-user product URLs (`app.lighter.xyz` and `lighter.exchange`). It also documents an `?ask=` query-string mechanism used by agents to query the docs dynamically, which is a docs-tooling note rather than a venue-mechanism claim. No fee, parameter, or risk numbers appear here; the page is identity/positioning only.
