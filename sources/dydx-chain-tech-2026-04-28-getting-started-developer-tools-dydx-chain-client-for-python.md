# dYdX Chain Client for Python

## TL;DR
v4-client-py is the Python client for the v4 API, available on PyPI. Setup uses Python 3.9 (VS Code), with a Cython/Brownie/cytoolz dependency-order gotcha noted. Tooling/setup page only.
