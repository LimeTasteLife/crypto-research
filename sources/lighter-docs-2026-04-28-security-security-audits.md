# Security Audits

## TL;DR
Lighter publishes a list of completed smart-contract and circuit audits with downloadable PDFs. Auditors disclosed: Nethermind (LighterCore + LighterEvmDepositBridge, both 2025-09-22), Block (2025-04-08; Block & delta 2025-08-09), and several internal scope audits — Wrapper (2025-10-10), Desert exit (2025-05-11), and Spot (2025-11-24). Two distinct auditing firms (Nethermind, Block) plus internal/scope-named audits cover the core matching/bridge stack as well as wrapper, desert-exit, and spot subsystems. No payout or remediation status appears on this index page.
