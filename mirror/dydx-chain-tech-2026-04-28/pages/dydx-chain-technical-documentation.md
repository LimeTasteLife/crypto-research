# dYdX Chain Technical Documentation

Source: https://docs.dydx.community/dydx-chain-technical-docs/dydx-chain-technical-documentation

## Overview

On October 26, 2023 at 17:00 UTC, the dYdX Chain open source software was deployed and the first block of the dYdX Chain was created by a network of validators.

dYdX Chain is a proof-of-stake blockchain network built using the Cosmos SDK and leveraging CometBFT for consensus.
