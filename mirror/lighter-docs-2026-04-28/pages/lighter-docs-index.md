# Introduction

Lighter is a decentralized trading platform designed for security, scale, and performance in a zero-fee trading environment. It is the first exchange to offer verifiable order matching and liquidations while delivering performance comparable to traditional exchanges.

The Lighter platform is available at:

- https://app.lighter.xyz/
- https://lighter.exchange/
