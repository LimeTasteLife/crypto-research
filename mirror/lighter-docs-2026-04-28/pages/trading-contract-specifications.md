# Contract Specifications

Lighter Test Network currently supports perpetual futures markets for the following markets. Lighter Governance will continuously add new markets as the test network grows.

IMR, MMR, and CMR represent the Initial, Maintenance, and Close-Out Margin Requirements, respectively. For more information about the meaning of these fractions, refer to the liquidations-and-llp-insurance-fund page.

> Currently each deployed market has a funding period of 1 hour. Funding period is a configuration of each market, thus it might be different for some of the new market deployments.
