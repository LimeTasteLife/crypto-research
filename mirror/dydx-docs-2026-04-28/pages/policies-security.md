# Security

Source: https://docs.dydx.xyz/policies/security

## Independent Audits

The protocol has been audited by the Informal Systems team. Additional audits are planned as more protocol code is developed.

You can find all finalized audit reports in the v4_chain audits folder.

## Bug Bounty

With all core dYdX Chain (v4) software GitHub repos now made public, the community is invited to help identify vulnerabilities to improve the security of dYdX Chain.
