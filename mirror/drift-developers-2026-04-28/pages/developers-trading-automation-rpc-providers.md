# RPC Providers

Solana utilizes a network of RPC Nodes to serve data to users. These nodes require a lot of resources to run and therefore can be quite expensive to operate.

Some commonly used free RPC providers are insufficient for Drift bots because functions like `accountSubscribe` (websockets) and `getProgramAccounts` are commonly disabled. Helius has a generous free plan that is sufficient for getting started. Consider upgrading to a paid plan as you get more serious with operating bots.
